The app now uses a royalty-free online serious BGM automatically.

Current source:
https://cdn.pixabay.com/audio/2023/08/16/audio_4409385d79.mp3

Tips:
- Default volume is set to ~12% for audible but subtle playback.
- Browsers may still block audible autoplay on first load. The site will try autoplay and resume playback on the visitor's first click, keypress, or touch.
- If you want a local fallback or different track, replace the URL in `src/components/BackgroundAudio.tsx`.

Restart the dev server after updates:

```bash
npm start
```
